# Pull-to-refresh + freshness Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox syntax.

**Goal:** Pull down on Teraz/Miejsca to re-fetch live GIOŚ data (refetching the active place + all rows via one global signal), and show the data's age on Miejsca rows.

**Architecture:** A `RefreshProvider` holds a `signal` (bumped on pull) + a `refreshing` boolean (tied to the active place's refetch settle + an 8s safety timeout). `usePlaceReading`/`usePlaceDetail` add the signal to their effect deps (a bump refetches). `useRefreshSignal()` returns `0` when no provider is mounted, so the existing hook/screen suites need no changes. `RefreshControl` on both screens.

**Tech Stack:** TS strict, RN 0.86, Jest + @testing-library/react-native (render/renderHook ASYNC — await). No new dependency (`RefreshControl` is on board).

## Global Constraints
- No new dependency. · TS strict, no `any`. · `src/core` pure, 100% coverage. · files ≤200 / functions ≤40. · imports one-way (features→shared→core; features never import data). · behavior tests cite AC IDs.
- Spec `docs/specs/018-refresh.md` is authoritative. Model: active-place-tied `refreshing` + 8s timeout + debounce; NO in-flight counter. `useRefreshSignal()` defaults to `0` unwrapped.

```tsx
import {
  createContext, useCallback, useContext, useMemo, useRef, useState,
  type ReactNode,
} from 'react';

const SAFETY_MS = 8000;

type RefreshApi = { refresh: () => void; refreshing: boolean; settleActive: () => void };
const SignalCtx = createContext<number>(0);
const ApiCtx = createContext<RefreshApi>({
  refresh: () => {}, refreshing: false, settleActive: () => {},
});

export function RefreshProvider({ children }: { children: ReactNode }) {
  const [signal, setSignal] = useState(0);
  const [refreshing, setRefreshing] = useState(false);
  const timer = useRef<ReturnType<typeof setTimeout> | null>(null);
  const refreshingRef = useRef(false);

  const clear = useCallback(() => {
    if (timer.current) {
      clearTimeout(timer.current);
      timer.current = null;
    }
    refreshingRef.current = false;
    setRefreshing(false);
  }, []);

  const refresh = useCallback(() => {
    if (refreshingRef.current) return; // debounce while refreshing
    refreshingRef.current = true;
    setRefreshing(true);
    setSignal(s => s + 1);
    timer.current = setTimeout(clear, SAFETY_MS); // safety: never stick
  }, [clear]);

  const settleActive = useCallback(() => {
    if (refreshingRef.current) clear();
  }, [clear]);

  const api = useMemo<RefreshApi>(
    () => ({ refresh, refreshing, settleActive }),
    [refresh, refreshing, settleActive],
  );
  return (
    <SignalCtx.Provider value={signal}>
      <ApiCtx.Provider value={api}>{children}</ApiCtx.Provider>
    </SignalCtx.Provider>
  );
}

export function useRefreshSignal(): number {
  return useContext(SignalCtx);
}
export function useRefresh(): RefreshApi {
  return useContext(ApiCtx);
}
```
(Contexts have safe defaults → unwrapped usage never throws and `signal` is `0`.)
